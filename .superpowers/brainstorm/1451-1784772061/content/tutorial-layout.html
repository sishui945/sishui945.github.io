教程页面布局 — 选择你喜欢的方案

参考 runoob.com 风格，三种不同的教程阅读体验

A

经典三栏（推荐）

类似现有博客详情页的结构。左侧章节目录树 + 中间正文 + 右侧本文目录（TOC）。最大程度复用现有组件。

B

沉浸式两栏

左侧固定可折叠的章节导航 + 右侧全宽正文。干净、专注阅读，类似 GitBook/文档站风格。

C

顶部导航式

顶部横向章节目录（面包屑/标签页式）+ 下方正文。更少的空间占用，适合移动端优先。

方案 A — 三栏布局预览

📘 C++ 教程
📘 CSS 教程
本文目录

优点

  • 复用 BlogDetailView 的三栏结构
  • 左侧导航 + 右侧 TOC 双辅助
  • 用户已有的浏览习惯无需改变

缺点

  • 三四百字的窄正文区太挤
  • 移动端三栏变竖向堆叠

方案 B — 两栏布局预览

优点

  • 正文区域宽敞，阅读体验好
  • 深色侧边栏形成视觉锚点
  • 类似 GitBook / Vue 文档站，用户熟悉

缺点

  • 没有本文目录，长教程定位困难
  • 需要新建组件，不复用现有结构

方案 C — 顶部导航式预览

优点

  • 最省空间，移动端友好
  • 顶部导航一眼看到所有章节

缺点

  • 章节多了横向放不下
  • 缺少层级结构感，不如树形直观
