三个区域的功能

左栏 当前教程目录 — 正在阅读的教程的全部章节，当前章节高亮。可滚动。类似书的目录页。
中栏 正文内容 — Markdown 渲染的文章，上下有"上一节/下一节"翻页按钮。
右栏 分类导航树 — 层级式类别菜单，可折叠展开。列出所有可用的教程。点击切换到其他教程。

教程列表页（/tutorials）预览

每个教程一张卡片，显示标题、简介、章节数。按分类分组展示。

后端数据模型

模型 字段 说明
Tutorial
教程		 id, title, slug 基本标识
description 简短介绍
category → Category 所属分类（外键）
publishedAt, updatedAt 时间戳
chapters → Chapter[] 章节列表（一对多）
Chapter
章节		 id, title, slug 基本标识
order 排序序号（Int，决定章节顺序）
content Markdown 正文
tutorial → Tutorial 所属教程（外键）
Category
分类		 id, name, slug 基本标识
parent → Category? 父分类（自引用，支持层级）
tutorials → Tutorial[] 此分类下的教程
